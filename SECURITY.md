# Security Policy / 安全政策

## English — Primary

### Reporting a vulnerability

Please use this repository's **Security** tab and open a private Security Advisory when the feature is available. Do not publish credentials, exploit details, private player data, wallet material, or production configuration in a public Issue.

If private reporting is unavailable, open a minimal public Issue asking the maintainer to enable a private reporting channel. Include no sensitive details in that Issue.

### Scope

Reports may cover source published in this repository, dependency risks, authentication or authorization boundaries, server-authority bypasses, ownership or settlement violations, and accidental exposure of secrets or private data.

This repository is a development snapshot. It does not represent a production service, live wallet, mainnet deposit or withdrawal system, or production Ordinals activation flow.

### Response

The maintainer will acknowledge valid reports through GitHub, assess affected public versions, and publish a sanitized resolution when disclosure is safe. No service-level response time is currently promised.

## 中文 — 完整对应版本

### 报告漏洞

如果 GitHub 支持，请使用本仓库的 **Security** 页面创建 Private Security Advisory。不要在 Public Issue 中公开 Credential、Exploit Detail、Private Player Data、Wallet Material 或 Production Configuration。

如果 Private Reporting 暂不可用，可以创建一个最小化 Public Issue，请求维护者启用私人报告渠道。该 Issue 不得包含任何敏感细节。

### 范围

报告范围可以包括本仓库公开的 Source、Dependency Risk、Authentication 或 Authorization Boundary、Server-authority Bypass、Ownership 或 Settlement Violation，以及 Secret 或 Private Data 的意外暴露。

本仓库是 Development Snapshot，不代表 Production Service、Live Wallet、Mainnet Deposit / Withdrawal System 或 Production Ordinals Activation Flow。

### 响应

维护者会通过 GitHub 确认有效报告、评估受影响的 Public Version，并在可以安全披露时发布脱敏后的处理结果。目前不承诺 Service-level Response Time。
