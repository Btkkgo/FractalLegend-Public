# FAQ / 常见问题

## English — Primary

### What is Fractal Legend?

A browser-native Legend-style MMORPG under development for the Fractal / Bitcoin ecosystem.

### Is the game playable now?

Accepted browser and server technical slices are playable for validation. There is no complete public MMORPG release.

### Why Fractal?

The project is exploring a Bitcoin-aligned environment for higher-throughput game interactions, digital identity, and economic rules.

### Why Bitcoin?

Bitcoin provides the broader ownership and provenance context for the intended asset ecosystem. This direction does not imply that mainnet integration is already live.

### How will Ordinals work?

The planned path verifies ownership and metadata, maps an eligible asset to reviewed game definitions, applies activation requirements, and only then exposes an activated game asset.

### Does owning an Ordinal make me stronger?

Not automatically. On-chain rarity cannot bypass balance, progression, eligibility, activation, server validation, or versioned mappings.

### Is FB live?

An internal server-authoritative FB Ledger Foundation exists from G11, and G12 uses it for atomic player Trade settlement. A production economy, wallet, real deposit, and withdrawal are not live.

### Are Contribution Points live?

G13 accepted an internal, non-transferable Contribution Ledger with a versioned 1:1 eligible FB system-spend rule. G14 accepted atomic linked FB refund/reversal and Contribution compensation, including recovery debt for already-used points. Ordinary Ledger refunds still fail closed; there is no real gameplay spend producer or production Contribution spending.

### Can I deposit or withdraw FB now?

No. Wallets, real deposits, withdrawals, broadcast, confirmation, and reorg handling are not implemented.

### Will there be mining?

Mining is planned around a capped global Black Iron emission pool and validated Mining Power. It is not implemented.

### Will there be trading?

G10 completed the item Trade Foundation; G12 added atomic item + FB player Trade settlement with 0% fee. A formal Trade UI, Marketplace, and Auction are not implemented.

### Will there be guilds and siege?

They are planned. No accepted Guild or Siege implementation exists.

### Will it run in a browser?

Yes, browser-native play is a core direction. Current browser slices are technical milestones rather than a complete product.

### Will mobile be supported?

Mobile support is a future roadmap item. No production mobile release is announced.

### When does it launch?

No public launch date has been announced yet. Development is milestone-driven rather than deadline-driven.

## 中文 — 完整对应版本

### Fractal Legend 是什么？

一款正在为 Fractal / Bitcoin 生态开发的浏览器原生传奇风格 MMORPG。

### 现在可以玩吗？

已验收的 Browser 与 Server 技术切片可以用于验证。目前没有完整公开 MMORPG Release。

### 为什么选择 Fractal？

项目正在探索一个 Bitcoin-aligned 环境，用于更高吞吐的游戏交互、Digital Identity 与 Economic Rule。

### 为什么选择 Bitcoin？

Bitcoin 为目标资产生态提供更广泛的 Ownership 与 Provenance 背景。该方向不表示 Mainnet Integration 已经上线。

### Ordinals 将如何工作？

规划路径会验证 Ownership 与 Metadata，把符合条件的资产映射到经过审核的 Game Definition，应用 Activation Requirement，然后才暴露 Activated Game Asset。

### 持有 Ordinal 会让我变得更强吗？

不会自动变强。On-chain Rarity 不能绕过 Balance、Progression、Eligibility、Activation、Server Validation 或 Versioned Mapping。

### FB 上线了吗？

G11 已建立内部 Server-authoritative FB Ledger Foundation，G12 使用它完成原子玩家 Trade Settlement。Production Economy、Wallet、真实 Deposit 与 Withdrawal 尚未上线。

### Contribution Point 上线了吗？

G13 已验收内部、不可转账的 Contribution Ledger，采用版本化的 1:1 合格 FB System Spend 规则。G14 已验收原子关联 FB Refund/Reversal 与 Contribution Compensation，包括已使用积分的 Recovery Debt。普通 Ledger 退款仍默认拒绝；尚无真实游戏消费 Producer 或生产用 Contribution 消费。

### 现在可以充值或提现 FB 吗？

不可以。Wallet、真实 Deposit、Withdrawal、Broadcast、Confirmation 与 Reorg Handling 尚未实现。

### 会有 Mining 吗？

Mining 计划围绕有上限的 Global Black Iron Emission Pool 与经过验证的 Mining Power 设计，目前尚未实现。

### 会有交易吗？

G10 已完成 Item Trade Foundation；G12 新增原子 Item + FB 玩家 Trade Settlement，手续费为 0%。正式 Trade UI、Marketplace 与 Auction 尚未实现。

### 会有 Guild 与 Siege 吗？

它们处于规划阶段。目前没有已验收的 Guild 或 Siege 实现。

### 会在 Browser 中运行吗？

会。Browser-native Play 是核心方向。当前 Browser Slice 是技术里程碑，不是完整产品。

### 会支持 Mobile 吗？

Mobile Support 是未来 Roadmap 项目。目前没有宣布 Production Mobile Release。

### 什么时候上线？

目前尚未公布正式上线日期。项目以阶段里程碑和实际验收结果推进，而不是以未经验证的固定发布日期推进。
