# Build in Public / 公开开发

## English — Primary

Fractal Legend publishes engineering evidence as the project advances:

- Code and stable commits
- Architecture Decision Records
- Devlogs and curated Interaction Records
- Test results and sanitized validation screenshots
- GitHub Issues, milestone status and retrospectives
- Known failures, environment limitations and unimplemented boundaries
- Roadmap changes and public presentation assets

Build in Public does not mean publishing secrets, personal accounts, credentials, private databases, protected Legacy archives, restricted binary assets, wallet private data, or local machine paths.

Every public engineering document uses English Primary followed by a complete Chinese version. Branch names, commit messages, code, APIs, schemas, test names, configuration keys, environment variables, protocol identifiers, and Canonical identifiers remain English.

### Status vocabulary

- **FOUNDATION COMPLETE:** a bounded technical milestone passed acceptance.
- **IMPLEMENTED:** code exists and its stated scope is verified.
- **IN REVIEW:** candidate work exists but acceptance is incomplete.
- **IN DEVELOPMENT:** active product work without a closed acceptance boundary.
- **NEXT:** the next authorized milestone after current gates close.
- **PLANNED:** approved direction without implementation.
- **RESEARCH / EXPLORATORY:** a direction under investigation.

Artwork and marketing copy are never test evidence. Technical screenshots and promotional assets remain separate.

X posts are prepared as English Primary plus complete Chinese review text and are published manually by the project owner. Codex does not publish them.

## 中文 — 完整对应版本

Fractal Legend 会随着项目推进公开工程证据：

- Code 与稳定 Commit
- Architecture Decision Record
- Devlog 与整理后的 Interaction Record
- Test Result 与脱敏 Validation Screenshot
- GitHub Issue、Milestone Status 与 Retrospective
- Known Failure、Environment Limitation 与未实现边界
- Roadmap 变化与公开展示素材

Build in Public 不表示公开 Secret、个人账号、Credential、Private Database、受保护 Legacy Archive、受限制 Binary Asset、Wallet Private Data 或本地机器路径。

每份公开工程文档采用 English Primary，随后提供完整中文版本。Branch Name、Commit Message、Code、API、Schema、Test Name、Configuration Key、Environment Variable、Protocol Identifier 和 Canonical Identifier 保持英文。

失败也会公开：Known Failure、Environment Limitation、未通过的 Gate 与后续关闭证据都属于工程记录的一部分。

### 状态词汇

- **FOUNDATION COMPLETE：**有边界的技术里程碑已通过验收。
- **IMPLEMENTED：**Code 已存在，且所述范围已验证。
- **IN REVIEW：**Candidate 工作已存在，但验收尚未完成。
- **IN DEVELOPMENT：**正在开发，尚无关闭的验收边界。
- **NEXT：**当前 Gate 关闭后的下一个已授权里程碑。
- **PLANNED：**已有方向，但尚未实现。
- **RESEARCH / EXPLORATORY：**仍在研究的方向。

Artwork 与 Marketing Copy 绝不是 Test Evidence。Technical Screenshot 与 Promotional Asset 必须分开。

X Post 以 English Primary 加完整中文审核稿准备，由项目所有者手动发布。Codex 不会自动发布。
